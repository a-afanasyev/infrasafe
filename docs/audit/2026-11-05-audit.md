## 1. Executive summary

1. **Прямых обходов AuthN/AuthZ, SQL-инъекций (271 вызов `.query`, ~40 динамических — все по whitelist), XSS, SSRF, path traversal не найдено.** Периметр снаружи выглядит образцово: только 80/443/32323, TLS 1.2/1.3 без слабых шифров, 421 на чужой Host, отказ без SNI, полный набор security-заголовков на всех наших страницах, подделанные JWT (`alg=none`, мусор) отвергаются, вебхуки и телеметрия без подписи — 401, подмена `X-Forwarded-For` лимит не сбрасывает.
2. **P1 — два пути DoS через вход для любого аутентифицированного пользователя (включая роль `user`).** `S-INJ-1`: квадратичный regex в `validatePassword` (`authService.js:658`) — один `POST /auth/change-password` с паролем в 1 МБ блокирует event loop на минуты (воспроизведено: 100 k символов → 6 с). `S-INJ-2`: выборка метрик контроллера без `LIMIT` плюс ключ кэша из сырых `startDate/endDate` — каждый уникальный запрос кладёт в кучу всю историю контроллера; латентно, пока телеметрии нет.
3. **P1 — на обеих площадках PostgreSQL 15.4 (образ от 14.08.2023).** Compose с 11.10.2026 закрепляет `postgis/postgis:15-3.5` по digest, но контейнер не пересоздавали — пропущены патчи 15.5…15.18 (в т. ч. CVE-2024-7348 в `pg_dump`, который крутит ежедневный бэкап). Это же первый пункт заявки УК от 23.10 — подтверждён.
4. **P2 — живьём подтверждён обход edge-лимита credential-эндпоинтов УК** (`S-PERIM-1`): `/uk/api/v2/%61uth/login` проходит allowlist и rewrite, но не попадает в зону `uk_api_cred` (20 r/min) — 26 запросов подряд без единого 429 против 429 после 11 на нормальном пути. Перебор паролей УК ускоряется в 6–9 раз.
5. **P2 — наши HttpOnly-куки (`access_token`, `refresh_token`, `temp_token`, path=/) уходят во все апстримы `/uk/*`** (`S-PERIM-2`): в живых конфигах обоих edge нет ни одной `proxy_set_header Cookie`. Любой логгер в чужом стеке получает рабочий refresh-токен админа.
6. **P2 — DoS админа через блокировку аккаунта** (`S-AUTH-1`): 5 неверных паролей по известному логину `admin` (лимит на IP — 10) блокируют вход на 15 мин **и гасят живые сессии**. На проде намеренно не воспроизводилось.
7. **P2 — расследование инцидента по логам невозможно** (`S-PERIM-4`): неудачные входы не логируются, IP нет ни в одном app-логе, nginx и app не связаны request-id, CRUD-мутации админа не журналируются. Плюс `S-INJ-3`: CRLF в логине без аутентификации подделывает строки консольного лога.
8. **Хосты в целом здоровы** (fail2ban, ufw на profk ровно 32323/80/443, ключи SSH опознаны, `.env.prod` 600, Redis с паролем, резервные копии свежие на обеих, TLS до 18.12.2026/02.01.2027). Хвосты: WireGuard на .105 `privileged + SYS_MODULE + label=disable + :latest` (образ 02.2025, UDP 51820 наружу) — второй пункт заявки УК; 6 ГБ build-cache на profk без prune; остатки `extmon` на .105 (cron каждые 5 мин); ключевой мусор в `~/.ssh` на .105.
9. **Заявка УК от 23.10 — сверка:** п.1 (образы) подтверждён; п.2 (дрейф `nginx.profk.conf`) **уже закрыт** PR #320/#321 — живой конфиг совпадает с репозиторием, остаётся снести 9 `.bak` и добавить `location ~ /\.` (на profk `/.env` и `/.git/HEAD` отдают 200 с картой); п.3 (CSP `assets.profk.uz`) подтверждён, низкий приоритет; п.4 (токен на `/api/uk-buildings-metrics`) **неактуален** — на обеих площадках без токена и с неверным токеном ответ 401.
10. Код дельты (117 коммитов с 22.09) корректен: 25+ правок, каждая с тестом, гонки закрыты по существу (`FOR UPDATE`, CAS по jsonb, атомарный UPSERT). Из нового — только P3 (`C-1…C-10`). Простота по-прежнему 6/10: мёртвые методы, batch-маршруты без потребителя, 4,4 k строк swagger, `trash/` 58 МБ в индексе.

## 9. Проверено и чисто / не проверено

**Чисто (находок нет):** SQL-инъекции (прямые, вторичные, через идентификаторы, `INTERVAL`, `ST_*`); SSRF (единственный исходящий вызов — `ukWebhookClient`, allowlist хостов, запрет приватных диапазонов и редиректов, таймаут 5 с); command injection / path traversal / десериализация (`child_process`, `eval`, `vm`, upload, XML/YAML — отсутствуют); prototype pollution из `req.body`; криптография (AES-256-GCM + HKDF + случайный IV, bcrypt-12, `timingSafeEqual` везде, CSPRNG); HMAC вебхуков и телеметрии (каноникализация hex, окно 300 с, дедуп Redis NX); default-deny allowlist (регистр, слэши, HEAD, OPTIONS — fail-safe); temp-token 2FA как access — невозможен; IDOR — нет пользовательских ресурсов; mass assignment — нет user-CRUD; куки HttpOnly/Secure/SameSite=strict; CSRF Origin-guard на всех cookie-мутациях; `/internal/metrics` fail-closed и не проксируется; токены в `localStorage` — нет (запись в CLAUDE.md про `admin_token` устарела); `fetch`-перехватчик не утекает Bearer; 40+ DOM-sinks карты через DOMPurify fail-closed; секреты в текущем дереве — нет; CI (SHA-пин actions, минимальные права, нет `pull_request_target`); `generator/` на проде не запущен; docker-логи ротируются демоном; AAAA нет (IPv6-обходы неприменимы).
